# Readable host installation diagnostics

Host users need an understandable next step after setup and an honest distinction between local
hook registration, observed local events, live host execution and saved task data. Add a human
view of existing diagnostics without changing the default JSON contract or enabling hooks.

This is an initial slice of the larger host-compatibility plan. Real-client verification, safe
repair, old-hook detection and OpenCode v2 support remain future work.
