# Automatic session recovery around native compaction

## Why
Instruction-only continuity depends on the host remembering to read workflows. Shared intake hints
cannot safely identify concurrent native sessions; external state is not hidden model reasoning.

## What changes
Add an offline vendored lifecycle runtime, optional Codex/Claude command registration, immutable
bounded durable-state capsules and workspace/native-session bindings. Add a separate interruption
trial driver and explicit BLOCKED evidence for unavailable hosts. Native conversation compression
remains host-owned; Kiro command support and live claims require actual evidence.
